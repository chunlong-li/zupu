# Windows 客户端（绿色版 + 安装版）

## 三种交付物

| 产物 | 大小 | 形态 |
|---|---|---|
| `族谱客户端安装包v<版本>.exe` | **15 MB** | **在线下载安装器（GUI）**：原生 Win32 自绘窗口，显示下载进度，下完校验 sha256 → 解压 → 建桌面快捷方式 → 写卸载项 |
| `族谱客户端v<版本>.msi` | **193.8 MB** | **离线安装包（单文件）**：WiX 原生 MSI，自带全部文件，双击进标准安装向导；不需要联网 |
| `族谱客户端v<版本>-绿色版.zip` | **235.1 MB** | 解压即用 |

### 为什么在线安装包只有 13.8 MB

安装器是**裁剪 + 自包含**的控制台程序（约 13 MB 是 .NET 运行时下限），
不带客户端本体——本体从更新源现下（和自动更新同一套逻辑：`Client/latest.json` → 下载 → sha256 校验 → 解压）。

> 之前那版 68.5 MB 是把整个客户端打进 .NET 单文件 bundle，除了大，还有个坑：
> 单文件启动时要把原生库解到 `%TEMP%\.net`，该目录不可写时进程直接退出（`0x8000809F`，表现为「点了没反应」）。
> MSI 和这个 13.8 MB 安装器都不需要解包，没有这个问题。

### 构建

```powershell
# 1) 客户端本体（已不含 WPF，见改动说明 v1.2.0.1113.5）
dotnet publish windows-client\ZupuClient.csproj -c Release -r win-x64 --self-contained true -o publish-cef

# 2) 精简（必做，否则包体会大 45 MB）
#    · locales 只留 zh-CN/zh-TW/en-US/en-GB；删 *.pdb/*.xml/*.lib/*.exp
#    · 删卫星目录 cs/de/es/fr/it/ja/ko/pl/pt-BR/ru/tr/zh-Hans/zh-Hant
#    · 删 32 个 WPF 专属文件（自包含发布会把整个 WindowsDesktop 运行时复制进来）：
#      Presentation* / WindowsBase / System.Xaml / ReachFramework / UIAutomation* /
#      System.Printing / System.Windows.Controls.Ribbon / System.Windows.Presentation /
#      System.Windows.Input.Manipulations / System.Windows（正好这个名字）/
#      WindowsFormsIntegration / wpfgfx_cor3 / PenImc_cor3 / D3DCompiler_47_cor3 / vcruntime140_cor3
#      ⚠️ 千万别用 System.Windows* 通配，会误删 System.Windows.Forms（WinForms 必需）

# 3) 在线安装器（裁剪单文件）
dotnet publish ZupuInstall\ZupuInstall.csproj -c Release -r win-x64 --self-contained true -o install-out

# 4) 离线 MSI（WiX 5；需要 WixToolset.UI.wixext）
wix build ZupuSetup\msi\installer.wxs -arch x64 -ext <WixToolset.UI.wixext.dll> -out dist\族谱客户端v<版本>.msi

# 5) 绿色版：publish-cef + 使用说明.txt + 「启动（数据放本目录）.bat」打成 zip
```

参考体积（v1.2.0.1113.5）：发布目录 474 MB / 更新包 215.2 MB / MSI 177.3 MB / 在线安装器 13.8 MB。

MSI 注意：程序集/包内名称用 **ASCII**（`ZupuSetup`、`ZupuInstall`），中文只放在显示名和文件名上——
中文程序集名会让 .NET 单文件宿主起不来。`Codepage="936"` 必须写，否则中文串在 MSI 里会报 WIX0311。

### 安装器参数

```
族谱客户端安装包.exe                      在线安装（交互）
族谱客户端安装包.exe --quiet --dir "D:\族谱" --desktop --autostart --no-run
族谱客户端安装包.exe --package app.zip    离线安装（用本地包，不联网）
族谱客户端安装包.exe --feed <清单地址>     换更新源

msiexec /i 族谱客户端v1.2.0.1113.4.msi /qn INSTALLFOLDER="D:\族谱" ALLUSERS=2 MSIINSTALLPERUSER=1
```

环境变量 `ZUPU_SETUP_DESKTOP` 可把「桌面」指到别的目录（企业部署/自动化测试）。
快捷方式优先走 COM，裁剪环境里 COM 不可用时自动回落系统 PowerShell 创建。

## 版本号规则（发版必读）

- 三段 `n.n.n` **固定**；发**正式版**时第三段 +1（一、二段等用户指定）。
- 加功能 / 修 bug 发**测试版**：`<三段>.<MMDD>.<当天第几次>`，如 `1.2.0.1112.1`。
- 落到 csproj 两处：`<Version>` 写三段（合法程序集版本），`<InformationalVersion>` 写完整号。
- 界面上显示、更新比较、更新包清单里的 `version` 都用**完整号**；需要三段时用 `ClientUpdater.BaseVersion`。

## 编译

```powershell
cd windows-client
dotnet publish -c Release -r win-x64 --self-contained true -o ..\publish-cef
```

产物在 `publish-cef/`，整个文件夹就是**绿色版**（双击 `ZupuClient.exe` 即用，
不需要装 .NET，也不需要装 WebView2）。

> 本机没有系统级 .NET SDK 时，用便携版 SDK 并重定向临时目录，见 `改动说明.md` 第四节。

## 发布包结构

```
族谱客户端v1.1.0/
├── app/              ← 把 publish-cef/ 里的所有文件放进来
├── 安装.bat          ← 双击安装（免管理员，建桌面快捷方式）
├── 安装程序.ps1
├── 改动说明.md
└── 打包说明.md
```

打包成 zip 即为「绿色版 + 安装程序」一体的发布包：

- **绿色使用**：直接运行 `app\ZupuClient.exe`；
- **安装**：双击 `安装.bat` → 装到 `%LOCALAPPDATA%\ZupuClient` + 桌面快捷方式 + 开始菜单。

## 依赖

| 项 | 说明 |
|---|---|
| 浏览器内核 | **CefSharp 156**（Chromium 156），随 `app/` 一起分发，无需系统安装 |
| VC++ 运行库 | 需要 2015-2022 x64 运行库（Win11 通常自带；缺失时装 `vc_redist.x64.exe`） |
| .NET | 不需要（自包含发布） |
| WebView2 / Edge | **不需要** |

## 发布前可裁剪（可选，省约 61 MB）

```powershell
$out = '..\publish-cef'
# 只保留 4 个语言包（CEF 只加载 Locale 对应的那个）
Get-ChildItem "$out\locales" -File |
  Where-Object { $_.Name -notin @('zh-CN.pak','zh-TW.pak','en-US.pak','en-GB.pak') } |
  Remove-Item -Force
# 去掉调试符号与用不到的 .NET 语言资源
Get-ChildItem $out -Recurse -File -Include *.pdb,*.xml,*.lib,*.exp | Remove-Item -Force
Get-ChildItem $out -Directory |
  Where-Object { $_.Name -match '^(cs|de|es|fr|it|ja|ko|pl|pt-BR|ru|tr)$' } |
  Remove-Item -Recurse -Force
```

## 数据目录

默认 `%LOCALAPPDATA%\ZupuClient`（`settings.json`、`cef-cache`、日志）。
设置环境变量 `ZUPU_DATA_DIR` 可改到任意目录（便携/绿色部署）。
