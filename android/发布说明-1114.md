# Android 发布交接（2026-11-14 · 被控端同步）

给 NAS 上的 DSH：新功能代码已经全部落到这台 NAS 上，请按本文编译并发布在线更新。

## 一、这次改了什么

新增「局域网被控端同步」：手机（控制端）连上电脑（被控端）后，两端共用同一套网页界面，
只同步**页面位置**和**数据改动**，不传画面。连上后电脑使用手机的登录身份，且电脑只读。

## 二、编译

```bash
cd /vol1/1000/zupu/android
bash rebuild.sh
```

预期产物：`/vol1/1000/zupu/android/族谱v1.0.5.1114.1-release.apk`

`rebuild.sh` 会自动把旧的 `族谱v*-release.apk` 删掉，只留最新的一个。

### 如果编译报错

我只做了静态检查（本机没有 Android SDK），最可能出问题的地方：

1. **ViewBinding**：`activity_settings.xml` 里新增的 id 是 `rowRemote` 和 `tvRemoteState`，
   Kotlin 里用 `b.rowRemote` / `b.tvRemoteState`。如果报「Unresolved reference」，
   说明 ViewBinding 没重新生成 —— 删掉 `app/build` 后重跑一次即可。
2. **import**：`AppSettingsActivity.kt` 新增了 `DialogInterface / InputType / CheckBox / EditText /
   LinearLayout / TextView / AlertDialog` 的 import，都在文件头。
3. **assets**：`app/src/main/assets/zupu-sync.js` 必须存在，否则运行时注入会静默失败（不报编译错）。

## 三、发布在线更新

```bash
bash /vol1/1000/zupu/android/publish-update.sh            # 只发测试通道（推荐，版本号是测试号）
bash /vol1/1000/zupu/android/publish-update.sh --stable   # 同时更新正式通道 app-latest.json
```

脚本会：

1. 取最新的 `族谱v*-release.apk`；
2. 从 `app/build.gradle.kts` 读 `versionCode`（应为 23），从文件名读版本号；
3. 算 `size` 与 `sha256`；
4. 复制到 `/vol1/1000/Docker/gateway/packages/zupu/app/zupu-app-1.0.5.1114.1.apk`；
5. 写 `/vol1/1000/Docker/gateway/packages/zupu/app/app-beta.json`（`--stable` 时再写 `app-latest.json`）；
6. 用 curl 回读三个地址打印 HTTP 状态码。

### 清单格式（与现有 app-latest.json 一致）

```json
{
  "versionCode": 23,
  "versionName": "1.0.5.1114.1",
  "url": "https://zupu-update.lijiacore.com:4440/app/zupu-app-1.0.5.1114.1.apk",
  "size": 5482952,
  "sha256": "…",
  "notes": "被控端同步：手机横屏连电脑，操作与数据实时同步；连上后使用手机端身份；被控端只读跟随刷新",
  "minSdk": 24,
  "force": false,
  "stable": false
}
```

## 四、校验

```bash
curl -sk https://zupu-update.lijiacore.com:4440/app/app-beta.json | head -20
curl -skI https://zupu-update.lijiacore.com:4440/app/zupu-app-1.0.5.1114.1.apk | head -5
```

App 上「长按家族名」= 检查测试通道；「设置 → 检查 App 更新」= 正式通道。

## 五、回滚

把 `app-beta.json` / `app-latest.json` 改回原内容即可（versionCode 22 / 1.0.5 /
`zupu-app-1.0.5.apk`，该包仍在 `/app/` 里没删）。

## 六、这和电脑客户端无关

Windows/Linux 客户端的 Electron 工程在 `/vol1/1000/zupu/zupu-client-electron/`，
它的在线更新走 `Client/latest.json`，本次不涉及，需要另行打包发布。
