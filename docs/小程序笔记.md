# 族谱小程序（原生）开发笔记

目录：`miniprogram/`（微信开发者工具直接打开这个目录；`project.config.json` 里 appid 是 `touristappid`，正式开发换成自己的）

## 一、两种接服务器的方式（`miniprogram/utils/config.js` 一处切换）

| 模式 | 配置 | 域名要求 | 适用 |
|---|---|---|---|
| `MODE = 'http'` | `BASE_URL` | **HTTPS + 已备案 + 不能带端口**，还要在小程序后台配「request 合法域名」 | 有备案域名反代到 NAS |
| `MODE = 'cloud'`（当前默认） | `CLOUD_ENV`、`CLOUD_SERVICE` | **不需要域名、不需要备案、不用配合法域名** | 微信云托管/云开发 |

### 云托管模式怎么配
1. 小程序后台 → 开发 → 云开发 → 开通，拿到 **环境 ID**，填 `CLOUD_ENV`；
2. 云开发控制台 → 云托管 → 新建服务（名字填 `zupu`，与 `CLOUD_SERVICE` 一致）：
   - 代码用本仓库 `backend/`（已有 Dockerfile）；**容器端口用 80**，配置文件见 `deploy/cloud/container.config.json`
     （已写 `containerPort: 80` 与环境变量 `FAMILY_TREE_PORT=80`、`FAMILY_TREE_DATA_DIR=/data`）；
   - 部署时把这个文件作为「容器配置」；若控制台里手工填，就照着它填；
3. 小程序里用 `wx.cloud.callContainer`，请求头带 `X-WX-SERVICE: zupu`——已在 `utils/api.js` 里封装好；
4. 容器里跑的是普通 Go 服务，接口路径不变（`/api/...`）；
5. 数据目录 `/data` 必须挂 **CFS**（见下一节），否则重启即丢库。

## 二、⚠️ 数据库要单独处理
后端现在是 **SQLite 单文件**（`/data/familytree.db`）。云托管容器是**无状态**的，重启就丢：

- 方案 A（推荐先用）：挂 **CFS 文件存储**到 `/data`，SQLite 文件放上面；单实例前提下可用；
- 方案 B：换云数据库 MySQL/PostgreSQL（要改后端存储层，工作量大）；
- 方案 C：继续用你自己的 NAS 跑后端，小程序走 `http` 模式 + 备案域名。

## 三、页面与接口

| 页面 | 文件 | 用到的接口 |
|---|---|---|
| 登录 | `pages/login/index` | `POST /api/auth/login` |
| 成员列表 | `pages/members/index` | `GET /api/members` + `GET /api/branches`（搜索姓名/字/号、**房支筛选、世代筛选**、上拉分页 20/页） |
| 成员详情 | `pages/detail/index` | `GET /api/members/:id/detail`、`GET /api/members/:id/children`、（父母名用 `GET /api/members` 兜底匹配） |
| 我的 | `pages/mine/index` | 无（显示登录用户、接入方式、服务器；退出登录） |
| 世系图 | `pages/tree/index` | `GET /api/members/with-spouses`（按世代分层、父子连线、单指拖动、双指缩放、点节点进详情） |

已实测这些接口在 520 人库上返回 200：`/api/members`、`/api/members/8/detail`、`/api/members/8/children`、`/api/settings/family-surname`。

## 七、自检工具（不需要开发者工具）

```bash
cd miniprogram
node tools/check.js                                  # 静态检查：页面方法/wxml 引用/data 字段、app.json 页面存在性
node tools/smoke.js http://127.0.0.1:18099 <token>   # 真数据冒烟：用 node fetch 顶替 wx.request，跑三个页面的载入逻辑
```

本轮冒烟结果（520 人库）：成员列表 520 人、房支下拉 2 项、世代下拉 3 项、首屏 20 条、搜索命中 1、第 2 世筛出 2 人、详情「李渊博」载入、世系图 **520 节点 / 519 条连线**、拖动与复位正常 —— **13 项全通过**。

> 冒烟时发现并修掉一个真 bug：接口路径少了 `/api` 前缀（`utils/api.js` 现在统一拼 `API_PREFIX`），不修的话开发者工具里所有请求都会 404。
